# DeepSeek Harness Desktop (Windows)

DeepSeek Harness 的 Windows 桌面应用：安装后双击桌面图标即可在独立窗口中使用，
界面、样式、功能与 Web 版保持一致。

## 特性

- 单文件 EXE 安装包，每用户免管理员权限安装
- 双击桌面快捷方式自动启动，无需命令行
- 首次运行引导配置 DeepSeek API Key
- 本地服务仅绑定 `127.0.0.1`，数据保存在本机

## 使用

安装完成后，双击桌面「DeepSeek Harness」快捷方式启动。
首次使用请在「设置 → 模型」中配置 DeepSeek API Key，即可开始对话。
